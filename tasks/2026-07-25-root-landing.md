# 任务：方案 B——根路径对未登录访客显示落地页

## 背景与目标

现状：根路径 `/` 是主对话页，未登录访客一打开网址就被踢到登录页；
落地页藏在 /welcome 无人知晓。改后：未登录访客打开 `/` 自动到落地页，
已登录用户访问 `/` 照旧进主对话页，一切不变。

## 涉及文件 / 模块（AI 填）

- `app/routes/_app.tsx` —— 父 loader 增加根路径分支判断
- `app/routes/welcome.tsx` —— loader 增加"已登录回应用"闭环；title 带品牌

## 明确不做什么 ⚠️

- 不改对话页的 URL（不把对话页挪到 /chat，避免全局路径引用回归）
- 不动其他受保护页的拦截（/assets、/billing 等未登录照旧跳 /login）
- 不碰登录/注册/鉴权逻辑本身

## 验收步骤 ⚠️

1. 未登录（无痕窗口）打开 `/` → 地址栏变为 /welcome，看到落地页完整版块
2. 已登录打开 `/` → 直接进主对话页（不跳转、不闪烁）
3. 已登录打开 `/welcome` → 自动回到 `/`（闭环，不让老用户卡在营销页）
4. 未登录打开 `/assets` 等受保护页 → 照旧跳 `/login?next=...`

## 需要跑的验收命令（AI 填）

- `npm run typecheck`、`npm run test:run`
- 浏览器截图：未登录访问 `/` 的落地页

## 风险与注意点（AI 填）

- 不触碰"不可破坏"区，无需挑刺会话
- 重定向闭环检查：`/` 未登录→/welcome；`/welcome` 已登录→`/`；
  两种身份各走一边，无循环
- 已知取舍：URL 会显示为 /welcome（302），不是根域名 200 直渲染。
  换来的是零路由结构改动、零回归风险
