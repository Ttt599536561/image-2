# F-083：GIF 输出与生成配置保持

用户要求：适配 Image 2.6 GIF 生成；生成后保留模型、分辨率、尺寸等设置。

## 已核实事实

- 2026-11-06 官方指南：https://developers.openai.com/api/docs/guides/image-generation#generate-animated-gif-output 。文生图需显式 `output_format: "gif"`，默认 9 帧、200ms/帧，返回完整 GIF 的 `b64_json`。图片编辑接口不支持 GIF 输出。
- 官方 API 参考：https://developers.openai.com/api/reference/resources/images/methods/generate 。GIF 可能要求模型对应预览权限；不能从官网能力推断第三方网关及用户 Key 已开通。
- 线上最近含 GIF 的任务在约 270 秒上游超时，未收到格式拒绝；网站原请求没有输出格式字段，原存储只接受 PNG/JPEG/WebP。
- 网关现用模型名称 `gpt-image-2.6` 是此前用户指定且生产已成功的别名；不擅自改成官方 Sunburst 名称。

## 实现与验收计划

1. 保持当前 PNG 默认请求兼容，增加明确 GIF 选项；GIF 仅支持现有两个 2.6 模型和无参考图文生图。非法组合在下单前说明，不自动更换用户设置。
2. 将输出格式随任务冻结并持久化；worker 发送明确 GIF 参数，原样保存 GIF 字节及正确 MIME/扩展名。要求 GIF 却收到静态图时明确失败，不伪装成功。
3. 历史、预览及下载保留动画和正确文件类型，参数复用包含输出格式。
4. 本浏览器保存非敏感生成配置，刷新/重挂载/成功/失败均保留；API Key 沿用原有单独授权的记住逻辑。
5. 用真实两帧 GIF 夹具验证请求、存储、历史、下载和失败分支；运行类型检查、全单测、真库相关测试、完整生产构建 E2E、构建/密钥/audit/release 检查；独立审查后按原有受控升级发布。

不调用真实付费生成，不声称已验证该网关的 GIF 权限；不自动重试付费请求。

## 验证边界

GIF 接收检查签名、尺寸、调色板、完整数据块、结束符和至少两帧，并保持上游字节不变；不解码 LZW 像素（与现有 PNG/JPEG 的非解码验证边界一致）。独立审查确认损坏压缩内容仍可能通过结构检查；本轮不新增自行实现的图像解码器，不能把结构验收描述成对任意损坏图片的完整解码验证。
