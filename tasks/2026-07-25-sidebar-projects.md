## 背景与目标

现在左侧边栏的「最近」是一个按时间倒序的平铺会话列表，会话多了以后难以
查找。参考市面上 AI codex 类工具的侧栏形态，把会话按「项目」归类：

- 新用户默认没有任何项目；首次生成图片后，该会话自动归入系统创建的
  「默认项目」，用户看到项目名下挂着自己刚生成的会话记录。
- 项目可展开/收起、可排序、可重命名、可新建；项目内会话可长按拖动排序。
- 做完后用户能用项目把不同主题的生图会话归类管理，交互与参考图一致。

## 需求细则（对 owner 五条需求的可验收展开）

### R1 项目分组与默认项目

1. 侧边栏原「最近」区改为「项目」区（标题文案：项目）。
2. 从未生成过图片的账户：项目区为空（一个项目都没有），保留现有
   「还没有对话，点『新建生成』开始吧」空态提示。
3. 用户首次成功提交生成（服务端创建会话的那一刻）：若该用户还没有
   默认项目，自动创建名为「默认项目」的项目，并把新会话归入其中。
4. 此后每个新会话（点「新建生成」后的首次提交）都自动归入默认项目。
5. 项目行视觉：左侧一个文件夹图标 + 项目名称；项目名下方缩进列出
   属于该项目的会话记录（每条仍是可点导航的会话行，视觉参考效果图）。
6. 会话行在项目内保持现有的：当前会话高亮、悬浮显示重命名（铅笔）/
   删除（垃圾桶 + 二次确认）操作。

### R2 项目内会话长按拖动排序

1. 同一项目内，会话行支持**长按后拖动**排序：桌面端鼠标长按、移动端
   触摸长按，达到长按阈值后进入拖动态，松手落点生效。
2. 拖动范围仅限本项目内：拖到其他项目区域或项目外时**不生效**
   （回弹原位），不同项目之间的会话不可排序、不可移动。
3. 排序结果持久化到服务端：刷新页面、重新登录、换设备后保持。
4. 未达到长按阈值松手 = 普通点击，照常导航到该会话（不冲突）。

### R3 项目长按拖动排序

1. 项目行之间支持长按拖动排序（同样桌面/移动端均支持），排序结果
   持久化到服务端。
2. 「默认项目」是普通项目中的一员，同样参与排序。

### R4 项目展开 / 收起

1. 点击项目行（非图标区域），在「展开会话列表」与「隐藏会话列表」
   之间切换。
2. 点击项目行不发生路由跳转，不影响当前正在看的会话。
3. 展开状态按用户在浏览器记忆（localStorage），重新打开侧边栏/刷新
   后保持；默认项目首次出现时默认为展开态。

### R5 项目行悬浮操作：重命名 / 新建项目

1. 鼠标悬浮到项目行（整行）时，行尾出现两个图标：更多（`...`）和
   新建项目（`+`），与参考图一致；移出后隐藏。
2. 点击 `...`：出现下拉框，本期只有一项「重命名项目」。
3. 点击「重命名项目」：在网站中间弹出模态弹窗，输入框预填当前项目名，
   底部两个按钮「取消」「保存」；保存生效并关闭弹窗，取消/点击遮罩/
   按 Esc 放弃修改。
4. 点击 `+`：同样弹出居中弹窗让用户填写新项目名称，按钮为「取消」
   「保存」；保存后新项目出现在项目列表**首部（最上面）**并默认展开
   （owner 已确认，2026-07-25）。
5. 项目名规则：去首尾空格后非空、最长 50 字符；为空时保存按钮不可用
   或提示错误。允许与其他项目重名（靠 id 区分）。
6. 移动端没有 hover：项目行展开时或长按项目行时显示这两个图标
   （具体手势实现时定，以移动端可用为准）。

### R6 保持不变的既有行为

- 「新建生成」按钮行为不变：路由到 `/`，首次提交成功后服务端建会话
  （区别仅在于新会话现在归入默认项目）。
- 搜索对话：输入关键词后仍显示**平铺的搜索结果**（不按项目分组），
  清空搜索回到项目视图。
- 会话重命名 / 删除（含二次确认与「正看着被删会话回到新建态」）、
  会话标题搜索防抖等既有交互全部保留。

## 明确不做什么 ⚠️

- **不做删除项目**（下拉框本期只有「重命名项目」一项）。
- **不做会话跨项目移动**（拖出本项目即回弹，也没有菜单入口）。
- 不动计费、生成队列、generations 状态机、资产库、灵感库任何逻辑。
- 不做项目嵌套、不做项目图标自定义、不做项目内搜索。
- 搜索态保持平铺，不按项目分组。
- 不做会话/项目分页改造（沿用现有列表规模；若后续量大再单独立项）。

## 验收步骤 ⚠️

1. 全新账户登录：侧边栏项目区为空，显示空态提示。
2. 提交一次文生图：成功后侧边栏出现「默认项目」（文件夹图标 + 文字），
   其下缩进显示刚生成的会话记录，点会话可进入。
3. 再生成一张：新会话出现在默认项目内。
4. 长按默认项目内的会话并拖动：项目内顺序改变；刷新页面顺序保持；
   尝试拖到其他项目区域 → 回弹不生效。
5. 悬浮项目行点击 `+`，弹窗居中出现，输入「测试项目」保存：新项目
   出现在列表**首部**；再长按拖动项目行调整顺序，刷新后保持。
6. 悬浮项目行点击 `...` →「重命名项目」：弹窗预填当前名，改为
   「我的项目」保存，项目名更新；再打开弹窗点取消，名字不变。
7. 点击项目行：会话列表收起；再点：展开。刷新后展开状态保持。
8. 会话行的重命名/删除（含二次确认）在项目内照常工作；搜索对话时
   平铺结果不受影响。
9. 手机宽度下打开侧边栏抽屉：新建/重命名/排序/展开收起均可用。
10. `npm run typecheck` + `npm run test:run` + `npm run test:e2e` 全绿。

## 风险与注意点（AI 填）

1. **存量数据迁移（最大风险）**：现有用户的现有会话需要一次性归入
   各自自动创建的「默认项目」，迁移必须幂等、可按文件单独提交；
   迁移失败时的恢复按 deploy 手册恢复流程，不许蛮干。
2. 不触碰 CLAUDE.md「不可破坏」区（钱、队列、凭据），但涉及数据表
   结构变更 + 多新端点，**验收前安排一次挑刺评审会话**。
3. 长按手势与点击导航的冲突：未到阈值松手必须是点击；拖动中不得
   触发 NavLink 跳转。移动端侧边栏是抽屉，手势需在窄视口 e2e 验证。
4. `useConversations` 的 loader initialData 水合模式会被项目列表
   取代/并存，注意搜索态仍走旧 API，不要打破水合。
5. 排序并发：两端同时排序以服务端最后写入为准，前端乐观更新 +
   invalidate 兜底（沿用现有乐观更新模式）。
