## Search Console 操作

1. 在 https://search.google.com/search-console 添加“网址前缀”资源 `https://one-image2.tangguo.xin/`，已有该资源则直接选用。
2. 若需验证，选择 HTML 标记，把 `content` 值填入生产 `deploy/.env.production` 的 `GOOGLE_SITE_VERIFICATION` 并重建 Web 容器配置；不要把整个 meta 标签放入变量。值会按设计出现在公开首页，是网站验证标记，不是用户 API Key。也可以使用已拥有的 DNS 域名验证。
3. 用公开首页源代码确认验证标记存在，再点击 Google 的验证按钮。
4. “站点地图”提交 `https://one-image2.tangguo.xin/sitemap.xml`，包含 `/` 与 `/guide`。robots.txt 已声明同一地址；Google 下次抓取 robots 时可发现它。
5. 在“网址检查”分别输入首页与 `/guide`，运行实时测试、请求编入索引。查看后续“网页索引”和“效果”报告；没有登录/验证和控制台成功回执不能记作“已提交”或“已收录”。

Google 官方依据：[建立并提交站点地图](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)、[请求重新抓取](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl)。不使用已经退役的 sitemap ping，也不使用仅针对特定内容类型的 Indexing API 提交普通工具页面。
