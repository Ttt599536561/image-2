# 任务：/welcome 公开落地页（含后续三轮视觉改版）

> 本卡于 2026-07-25 补填：功能已在 2026-07-25 当天分四步完成并验收，
> 此卡按实际发生的情况回溯记录，供后续会话溯源。

## 背景与目标

产品 one-image2（AI 生图网站）原来打开就是登录页，新访客看不懂这个
网站能干什么、强在哪。需要一个公开落地页：未登录可访问，展示 image-2
模型的能力、站内真实作品、创作流程，并把访客引导到注册。

后续三轮改版均来自 owner 的观感反馈：
1. "图片像硬怼上去的，缺乏高级优雅的连贯体验" → 全页叙事+动效重构
2. "图片没有融入感，不像跟网站一体" → 占位图暖调重绘+画墙衬底
3. "图片之间大量留白、割裂" → 紧密照片墙（本卡最终形态）

## 涉及文件 / 模块（AI 填）

- `app/routes/welcome.tsx` —— 路由与 loader（取灵感库前 14 条）
- `src/components/landing/LandingPage.tsx` —— 页面主组件
- `src/components/landing/Landing.module.css` —— 全部样式（设计令牌驱动）
- `src/components/landing/Reveal.tsx` / `Reveal.module.css` —— 滚动显现动效
- `src/lib/placeholder.ts` —— 种子占位图（暖调低饱和渐变五色系）
- `src/components/landing/LandingPage.test.tsx` —— 组件测试

## 明确不做什么 ⚠️

- 不改登录/注册流程本身，只做引导跳转
- 不动灵感库数据表结构与审核逻辑（落地页只读 active 灵感卡）
- 不把根域名 / 指向落地页（"方案 B"）——owner 尚未拍板，落地页
  目前只在 /welcome
- 不引入第三方 masonry/动画库（分列与动效均手写实现）

## 验收步骤 ⚠️

1. 未登录打开 /welcome，看到完整版块：导航（one-image2 品牌+主题
   切换）→ Hero（左文案+右叠层浮动画卡+提示词打字机）→ 看见魔法发生
   （对话气泡演示）→ 画廊照片墙 → 三大能力 → 三步流程 → 特色条 →
   CTA → 页脚（由 image-2 模型驱动）
2. 画廊：图片铺满卡片无白框、缝隙 12px、各列高度均衡无整列空洞；
   鼠标悬停任一作品，浮现标题+分类标签+提示词
3. 主题：默认浅色；点导航主题按钮切深色，再点切回浅色
4. CTA（导航/hero/底部共 ≥3 处）均跳转 /register
5. 2560px 宽屏 5 列、1280px 4 列、窄屏 2 列，布局不破

## 需要跑的验收命令（AI 填）

- 最低门槛：`npm run typecheck`、`npm run test:run`
- 页面加跑：Playwright 截图逐屏核对（脚本临时写、用完即删）

## 风险与注意点（AI 填）

- 不触碰 CLAUDE.md "不可破坏"区（资金/扣费），无需挑刺会话
- SSR 项目：`useGalleryColumns()` 初始列数必须是固定值（5），
  挂载后再按 window.innerWidth 校正，否则 SSR 会炸
- 画廊分列用 LPT 装箱（按宽高比降序放最矮列），会重排作品显示顺序，
  仅用于视觉排布，不影响灵感库本身排序
