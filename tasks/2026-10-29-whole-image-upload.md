# F-081 整图单次上传与长上传预算

用户明确要求：网站直接一次上传整张图片，不切片；失败直接返回，上传时限延长。

已确定的实现：每图原字节FormData POST到现有`/api/studio/uploads`一次，不自动重试、不fallback到分片。后台整图收取预算20分钟，浏览器21分钟覆盖存储/响应；明确失败立即返回原任务卡失败。四图仍按顺序各自一次完整上传。用户主动点击原卡重试是新的显式尝试，仍复用原任务ID和已完成的图片。JSON15秒、图片4MiB/4张、owner/origin/限流保持。

需要同步核对Node HTTP服务整体requestTimeout，避免默认5分钟先于应用20分钟触发。现存分片迁移/暂存清理保留用于旧页面退场，不让新版客户端调用；不删数据表处理功能回退。

- [x] Client TDD：一次FormData包含完整原图；网络/HTTP/timeout只发一次，无分片请求；21分钟预算包含响应体。
- [x] Server TDD：20分钟收图、截止408，JSON15秒不变；生产Node HTTP超时覆盖上传预算。
- [x] E2E：截图粘贴完整原图，只POST一次；503/断连直接失败、generate零请求；四图顺序、用户主动重试保持ID。
