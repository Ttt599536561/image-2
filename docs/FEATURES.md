# 功能总清单

> 本文件是全站功能的"总账本"，AI 和人都以它为准判断"做完了没有"。
> 出处：Anthropic《Effective Harnesses for Long-Running Agents》的 feature list 机制。

## 使用规则（AI 必须遵守）

1. **只许改"状态"列，不许删除或改写任何条目。** 删除条目会导致功能漏测，是不可接受的行为。
2. 状态只有三种：`✅ 已验收`、`🚧 进行中`、`❌ 未实现/已损坏`。
3. 把条目标记为 `✅` 之前，必须亲自按"验收步骤"跑过对应测试/浏览器验证，并在当次 `docs/PROGRESS.md` 日志里贴出证据。
4. 新增功能必须先在 `tasks/` 建任务卡，验收后由 AI 把条目追加到本文件对应分类，编号顺延。
5. 每次新会话开始，先读本文件了解全局状态（见 CLAUDE.md 会话开始 SOP）。

## 状态说明

- 当前清单按 `0.2.0` 生产基线盘点（2026-07-24 接管会话建立）。
- 标注 `🚧` 的条目表示代码已实现但尚未在生产验收（如 v0.2.1 待部署功能）。
